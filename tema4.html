Tema 4

Llantas de Fórmula 1: la ventana de temperatura y el agarre

Fricción, coeficiente de fricción y fuerza normal

Caso de uso en Ingeniería del Software

En simuladores de automovilismo y en software de análisis de rendimiento, el comportamiento de las llantas se modela utilizando principios de fricción. El sistema debe estimar cuánto agarre ofrece un neumático según su temperatura, ya que esto afecta directamente la aceleración, el frenado y la capacidad de tomar curvas.

Un modelo físico permite representar de forma dinámica cómo cambia el rendimiento del vehículo durante la carrera, en lugar de usar un nivel fijo de agarre independiente de las condiciones de la pista o del estado de la llanta.

Modelo físico utilizado

El modelo básico de fricción relaciona la fuerza disponible con la fuerza normal mediante:

F_f = μN

Donde:

  • F_f: fuerza de fricción.
  • μ: coeficiente de fricción.
  • N: fuerza normal ejercida sobre la llanta.

También se puede distinguir entre el coeficiente de fricción estática y el coeficiente de fricción cinética:

F_s ≤ μ_s N
F_k = μ_k N

En el primer caso, μ_s representa el coeficiente de fricción estática, mientras que μ_k corresponde al coeficiente de fricción cinética. Estos modelos permiten comprender de forma básica cómo una fuerza de contacto puede limitar el agarre disponible.

Sin embargo, en una llanta de competición el valor efectivo de μ no permanece constante. Entre otros factores, cambia con la temperatura del neumático. Cuando la llanta se encuentra demasiado fría no alcanza su mejor nivel de agarre, mientras que al superar su zona óptima también puede perder rendimiento.

Carga vertical y agarre real

El modelo sencillo F_f = μN supone que el coeficiente de fricción permanece constante. Bajo esa condición, si la fuerza normal se duplicara, la fuerza de fricción disponible también se duplicaría.

Un neumático real presenta un comportamiento más complejo. Al aumentar la carga vertical sobre la llanta, el agarre total también aumenta, pero no necesariamente en la misma proporción. Por esta razón, el agarre real no puede representarse en todas las condiciones suponiendo un valor fijo de μ.

Este comportamiento se conoce como sensibilidad a la carga del neumático. Para un software de simulación resulta importante, porque utilizar únicamente un coeficiente fijo podría sobreestimar o subestimar la fuerza disponible durante una frenada, una aceleración o una curva.

Por eso, los modelos más completos pueden considerar variables como la carga, la temperatura y el estado del neumático para modificar dinámicamente el agarre disponible.

¿Por qué usar un modelo físico?

Si un videojuego o simulador asignara un mismo nivel de agarre para cualquier situación, el comportamiento del vehículo sería poco realista. El conductor no percibiría cambios al calentar las llantas o al exigir demasiado el neumático en curvas y frenadas.

Usar un modelo físico permite que el software ajuste el valor del agarre según la temperatura, la carga y otras variables, produciendo una simulación más útil para entrenamiento, análisis y diseño de estrategias.

La ventaja es que el vehículo puede responder de manera diferente ante distintas condiciones sin programar manualmente un comportamiento específico para cada situación. A cambio, el modelo requiere más variables y cálculos que una solución basada únicamente en un valor fijo de agarre.

Modelo utilizado para generar los datos

Para construir la visualización se utiliza un modelo matemático simplificado que representa una ventana óptima de temperatura. La finalidad es generar los datos de forma calculada y observar cómo cambia el coeficiente de fricción al acercarse o alejarse de una temperatura de referencia.

μ(T) = μmin + (μmax - μmin)e^(-(T - Topt)² / 2σ²)

Para esta representación se utilizaron los siguientes parámetros:

  • μmin = 0.75: valor mínimo utilizado en el modelo.
  • μmax = 1.22: valor máximo del coeficiente calculado.
  • Topt = 100 °C: temperatura óptima definida para el ejemplo.
  • σ = 22: parámetro que controla el ancho de la ventana térmica.

Cuando la temperatura se aproxima a 100 °C, el modelo produce un valor mayor del coeficiente de fricción. Al alejarse de esa zona, el coeficiente disminuye progresivamente.

Este modelo se utiliza únicamente con fines educativos. No representa la curva oficial de un compuesto específico utilizado en Fórmula 1.

Análisis

La gráfica muestra que el coeficiente de fricción aumenta mientras la temperatura se acerca a la zona óptima definida en el modelo. El valor máximo se alcanza en 100 °C, donde se obtiene μ = 1.220.

Cuando el neumático se encuentra por debajo de esa temperatura, el coeficiente calculado es menor. El mismo comportamiento se presenta al superar la zona óptima, haciendo que la curva disminuya nuevamente.

Esta visualización no intenta reproducir un compuesto real de Fórmula 1, sino demostrar cómo un programa puede transformar una variable física, en este caso la temperatura, en un valor dinámico de agarre.

En un simulador, ese valor puede utilizarse junto con la fuerza normal para calcular una fuerza disponible aproximada:

F_f(T) = μ(T)N

De esta manera, el agarre deja de ser una constante y pasa a depender del estado del neumático. Este tipo de comportamiento permite construir una simulación más flexible que un sistema basado únicamente en valores fijos.
