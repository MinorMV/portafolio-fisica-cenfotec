Sobre este portafolio

Este portafolio presenta cinco aplicaciones concretas de la física mecánica en sistemas tecnológicos y software. Cada tema analiza un caso específico, el modelo físico utilizado y un recurso de apoyo relacionado con la aplicación estudiada.

06

Conexión entre los temas

Aunque cada tema analiza una aplicación distinta, todos se relacionan mediante conceptos de cinemática y dinámica utilizados para representar sistemas físicos dentro del software.

El rastreo de un dron y el salto de un personaje utilizan conceptos como posición, velocidad y aceleración para determinar cómo cambia el movimiento con el tiempo. En ambos casos, el software necesita recalcular el estado del sistema a partir de variables físicas y no solamente reproducir una trayectoria previamente definida.

En el caso de la gravedad artificial también aparece la aceleración, pero aplicada a un movimiento circular. La aceleración centrípeta permite relacionar la velocidad de rotación y el radio del hábitat con la sensación de gravedad que experimentaría una persona en su interior.

Las llantas de Fórmula 1 agregan el estudio de las fuerzas. La fuerza de fricción y la fuerza normal determinan parte del agarre disponible entre el neumático y la pista, mientras que la temperatura modifica el comportamiento del sistema y obliga al software a trabajar con valores que cambian durante la simulación.

Finalmente, el control háptico también utiliza fuerzas, pero con un objetivo diferente: producir una respuesta física que el usuario pueda sentir. Mediante la relación entre fuerza y desplazamiento, el software puede modificar la resistencia del gatillo y representar diferentes situaciones dentro de un videojuego.

En conjunto, los cinco casos muestran una misma idea vista durante el curso: utilizar ecuaciones físicas permite que un sistema de software responda a condiciones variables de manera coherente. Esto ofrece una solución más flexible que depender únicamente de valores fijos, animaciones predeterminadas o comportamientos programados para un solo escenario.
