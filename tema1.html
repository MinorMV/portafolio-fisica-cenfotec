Tema 1

Rastreo y navegación de un dron de reparto

Cinemática en dos dimensiones

Caso de uso en Ingeniería del Software

En un sistema de reparto mediante drones, el software de navegación debe conocer en todo momento la posición del vehículo, la rapidez con la que se desplaza y cómo cambia su velocidad durante el recorrido.

Para lograrlo se utilizan principios de cinemática en dos dimensiones, ya que el movimiento del dron puede representarse mediante componentes sobre los ejes X y Y. Este modelo permite actualizar la trayectoria de forma dinámica y corregir cambios durante el vuelo.

Modelo físico utilizado

La posición del dron se representa mediante un vector de posición:

r(t) = x(t)i + y(t)j

La velocidad corresponde al cambio de posición con respecto al tiempo:

v(t) = Δr / Δt

En cada componente:

vx = Δx / Δt
vy = Δy / Δt

La magnitud de la velocidad se calcula mediante:

|v| = √(vx² + vy²)

La aceleración representa el cambio de velocidad con respecto al tiempo:

a = Δv / Δt

¿Por qué utilizar un modelo físico?

Usar ecuaciones de movimiento permite que el sistema de navegación calcule el comportamiento del dron en función de los datos que recibe durante el vuelo.

Si la trayectoria se programara únicamente mediante posiciones fijas o movimientos precalculados, el sistema tendría menos capacidad para reaccionar ante cambios de velocidad o desviaciones en la ruta. Un modelo físico permite recalcular la posición y el movimiento de forma continua.

Ruta simulada del dron

Para analizar el movimiento se generó una ruta simulada de 10 segundos, utilizando posiciones en los ejes X y Y. A partir de estos datos se calculan la velocidad y la aceleración del dron.

Análisis

Los resultados muestran un aumento progresivo de la posición del dron en ambos ejes. Entre el inicio y el segundo 10, la posición pasa de (0, 0) m a (95, 65) m. Al mismo tiempo, las componentes de velocidad aumentan de forma gradual, llegando a 14 m/s en X y 11 m/s en Y.

A partir de los cambios de velocidad se obtiene una aceleración aproximada de 1 m/s² en cada componente, cuya magnitud es de aproximadamente 1.41 m/s². Esto muestra que el movimiento no mantiene una velocidad constante, sino que el dron acelera progresivamente durante la ruta.

En un sistema de navegación, estos cálculos permiten comparar el movimiento esperado con los datos obtenidos durante el vuelo. Si la posición o la velocidad real se apartan de la trayectoria prevista, el software puede detectar la desviación y realizar una corrección sin depender de una secuencia de movimientos programada previamente.
